Local-first AI CLI receipts

Monthly usage reports without billing API calls.

cli-receipt reads Claude Code, Codex, and Copilot artifacts already stored on your machine, estimates cost, and renders terminal, HTML, and JSON receipts.

Sample monthly summary rendered from the repository asset.

Provider data stays local.

The main report reads local JSONL/session artifacts and keeps Claude, Codex, and Copilot totals separated by provider.

ProviderDefault sourceWhat is estimated
Claude Code`~/.claude/projects/**/*.jsonl`Model metadata, token counts, cache pricing, normalized aliases.
OpenAI Codex`~/.codex/sessions/**/*.jsonl`Daily `token_count` deltas, cached input pricing, priority/long-context modifiers.
GitHub Copilot`~/.copilot/session-state/*`Session shutdown summaries, model metadata, optional quota snapshots.

Fast enough for a one-off report, stable enough for hooks.

Run without installing.

npx cli-receipt report
npx cli-receipt report --output html,json

Install for repeated use.

Use a global install when a stable binary path is needed for Claude Code hooks.

Ship with checks.

`npm run release:check` runs the Node test suite and dry-runs the npm package.

Output shapes.

Terminal receipts are immediate, HTML heatmaps are readable in a browser, and JSON reports can feed later automation.

Private by default, estimates by design.

The report is local-first, but generated HTML and JSON can still reveal model names, usage timing, and estimated spend. Treat exports as private unless redacted.
